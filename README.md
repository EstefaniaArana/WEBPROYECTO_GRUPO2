# Aerolínea VIP – Grupo 02 (Segunda Entrega)

Sistema web monolítico de compra y reserva de pasajes 
## Cómo ejecutar
1. Ejecutar en SQL Server el script `Script_BD_AerolineaVIP.sql` (crea AerolineaVIP y AerolineaVIP_Identity).
2. Abrir la solución en Visual Studio y restaurar los paquetes NuGet.
3. Si el SQL Server tiene instancia, cambiar `Data Source` en Web.config.
4. Ejecutar con F5.
